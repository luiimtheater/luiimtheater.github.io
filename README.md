## 建議上傳方式

若 GitHub 網頁版提示檔案太多，請使用 `luiimtheater-v28-update-only.zip`：
1. 解壓縮更新包。
2. 在 GitHub Repository 按「＋ → Upload files」。
3. 將解壓後的內容拖入上傳區。
4. 等待上傳完成後 Commit changes。

更新包只包含本版實際變動與新增檔案，不必重傳整個網站。

# 雷音劇坊 Lui Im Theater 官方網站

## 本版內容

- 首頁：主視覺輪播、雷音識別、近期動向、關於雷音、後台影像、代表作品、團隊入口
- 近期動向：月曆 + 活動列表；目前已放入 2026/10/23 思劇場《青瞑的龍蛇無青瞑》
- 作品：《青瞑的龍蛇無青瞑》完整作品介紹、主創、巡演足跡與校園成果
- 團隊：成員卡片可點擊查看個人經歷；已新增行政統籌易芊
- Pages CMS：可編輯 `data/events.json` 的公開行程

## 上傳 GitHub

將本資料夾內所有檔案與資料夾上傳到 `luiimtheater/luiimtheater.github.io` repository 的根目錄，覆蓋同名檔案即可。

GitHub Pages：Repository → Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)`。

## 更新活動

活動資料位於 `data/events.json`，亦可於 Pages CMS 透過 `.pages.yml` 設定後編輯。
